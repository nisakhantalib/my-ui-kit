# Design tokens

Source of truth: `packages/ui/tokens/` (W3C Design Tokens format): palette, then semantic and component tokens per brand. See Foundations › Brands. `npm run tokens` generates the CSS custom properties and the typed `tokens` export below, and CI fails if they drift.

Use the CSS variables in web code (`var(--kit-primary)`) and the `tokens` object where CSS cannot reach: native status bars, charts, email templates.
