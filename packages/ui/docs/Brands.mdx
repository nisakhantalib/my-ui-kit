# One library, many brands

The same components, re-skinned only by tokens. `data-brand` works on any element, so a page can host two brands at once — the panels below are siblings on one page. Nothing in the components knows which brand it's in.

<div
  style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(280px, 1fr))', gap: 16, marginBottom: 40 }}
>
  {['civic', 'orchid'].map((brand) => (
    <div
      key={brand}
      data-brand={brand}
      className="sb-unstyled"
      style={{
        background: 'var(--kit-bg)',
        color: 'var(--kit-text)',
        fontFamily: 'var(--kit-font)',
        padding: 24,
        borderRadius: 'var(--kit-card-radius)',
        border: '1px solid var(--kit-border)',
        display: 'grid',
        gap: 16,
      }}
    >
      <strong style={{ fontSize: 18 }}>{brand === 'civic' ? 'Civic — ClinicBook SG' : 'Orchid — Orchid Bank'}</strong>
      <TextField label="Email" hint="We send the receipt here" />
      <Switch label="Notifications" defaultChecked />
      <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
        <Button>Continue</Button>
        <Button variant="secondary">Back</Button>
      </div>
      <Alert tone="success" title="Saved" />
      <div>
        <Badge tone="warning">Pending</Badge>
      </div>
    </div>
  ))}
</div>

## What a brand can change

| Tier            | Example                | Civic          | Orchid       |
| --------------- | ---------------------- | -------------- | ------------ |
| Semantic colour | `--kit-primary`        | blue           | violet       |
| Shape           | `--kit-radius`         | 10px           | 14px         |
| Component       | `--kit-button-radius`  | follows radius | 999px (pill) |
| Component       | `--kit-control-height` | 44px           | 48px         |
| Type            | `--kit-font`           | system UI      | Inter        |

## Enforced, not hoped for

Every brand must define exactly the same tokens, and every colour pair below is checked against WCAG when tokens are built. A brand that fails cannot be published.
